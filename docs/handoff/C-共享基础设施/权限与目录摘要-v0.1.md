## 一、目录分工（拍板口径）

| 角色 | 路径 | 放什么 |
|------|------|--------|
| 运行时·共享 | `/workspace/compute-shared/` | 公开证据、结构化知识、模板 |
| 运行时·AK 私域 | `/workspace/compute-ak-private/` | 会员 / 付费（隔离） |
| 运行时·出海私域（语义对齐） | `/workspace/compute-outbound-private/` | 与 B·99 **同语义**；不另定冲突规则 |
| 出海敏感**规范路径** | `算力双项目交接包/B-中国算力出海/99-敏感商务_仅本项目/` | 联系人、报价、合同、商务原文（权威） |
| 出海公开工作区 | `B/01`–`05` | 公开字段与脱敏产物 |
| AK 公开研究 | `算力双项目交接包/A-算力之王AK/` | 主文档、研究报告、证据表 |
| 交接叙事 / 设计 | `算力双项目交接包/C-共享基础设施/` | 目录·接口·权限摘要·设计文档 |
| 基建草稿 | `/workspace/compute-infra/` | 从本目录提炼/同步的工作副本 |

**原则**：研究知识 → shared / A·B 公开区；客户·报价·会员·商务 → 私域规范路径。禁止混仓、禁止双写两套敏感规则。
