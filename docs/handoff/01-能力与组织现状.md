## 一、任务1：实际具备的项目管理能力

### 1.1 能做

| 能力 | 结论 | 说明 |
|------|------|------|
| 创建独立 Bot | **可以** | `CreateAgent`：名称 + 职责描述（人设/指令） |
| 创建群聊 | **可以** | `CreateChannel`：站内群；**每群最多 6 人** |
| 配置 Bot 角色 | **部分可以** | 只能写入人设与协作约定；**不是**系统角色权限矩阵 |
| 将 Bot 加入群聊 | **可以** | 建群指定成员，或 `UpdateChannel` 加减人 |
| 创建和分配任务 | **可以** | `SendToAgent` 私聊/群聊派活；可设是否立刻叫醒 |
| 保存项目文档 | **可以** | 本机 Markdown、Canvas、Notion（已接） |
| 网络搜索 | **可以** | WebSearch / WebFetch 等公开检索 |
| 持续跟踪 | **部分可以** | Routine、任务队列、群内跟进；**无**独立跨 Bot 权限式看板产品 |

### 1.2 做不到 / 硬限制（不得假装已完成）

1. **系统级 ACL / 字段级权限**：无法从平台层隔离「谁可读客户报价/合同」。敏感隔离靠流程 + 分仓文档/库。
2. **删除 Bot / 删除群**：无删除工具，需用户在侧栏操作。
3. **新建侧栏分区**：现有分区可读，不能新建；新 Bot 可放未分组。
4. **改 Arthur 本机环境**：当前阶段不执行本地 Git/Python/DeepSeek 实操。
5. **未打开的来源**：不得写成「已核验」。
6. **擅自外发商务信息 / 产生费用**：不做。

### 1.3 权限配置诚实说明

| 类型 | 状态 |
|------|------|
| 人设中的职责与敏感数据隔离约定 | **已写入**（已创建但未系统配置） |
| 平台级读写 ACL、加密隔离、审计强制 | **无法配置**（仅规划流程） |
