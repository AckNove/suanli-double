## 可对外口径

1. **事实**：多源显示导电/N 型 SiC 衬底供给向少数厂商集中（TrendForce：2024 前四约 82%）。  
2. **非事实**：任一未经方法对齐的单一市占%（17.1% / 27.6% / 33.7% 等）不得单独作为付费结论。  
3. **引用模板**：必须带「机构名 + 年份 + N 型或导电型 + 收入法/未说明方法」。
