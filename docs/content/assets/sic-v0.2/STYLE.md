## 1. 定位

**财经科普讲解卡 / 白板信息图**，不是科幻芯片海报。故事优先、字幕优先、信息密度高但页面干净。

## 2. 调色

| 角色 | 色值（约） | 用法 |
|------|------------|------|
| 底色 | `#F7F4EC` 米白 / `#FFFFFF` 纯白 | 全屏底；允许极浅纸纹，禁止深空/霓虹渐变 |
| 主字 | `#1A1A1A` 近黑 | 标题、大字幕 |
| 副字 | `#4A4A4A` 深灰 | 说明、脚注 |
| 强调 | `#C45C26` 暖橙 或 `#2F5D8C` 沉稳蓝 | 箭头、关键数字、角标；每帧只用一种强调色 |
| 警示 | `#B33A3A` 砖红 | 「规划≠已实现」「IGBT≠SiC」等红框警示 |
| 弱信息 | `#8A8A8A` 中灰 | 旁支、免责小字 |
| 色块 | `#E8E2D6` / `#D9E4F0` 浅米色/浅蓝 | 分层卡片底，扁平无渐变玻璃 |

**禁止**：霓虹青紫、赛博网格、全息、高饱和青蓝金属、深黑 HUD 底。

## 3. 字体与排版

- 中文：黑体 / 思源黑体类无衬线；标题大、居中或左对齐清晰层级。
- 标题约全屏高 8–12%；关键字幕 6–9%；脚注 ≤4%。
- 单行字幕短句优先；数字用中文或阿拉伯均可，但**禁止**「市占 X%」单点。
- 留白充足：边距 ≥6%，卡片间距均匀，勿堆叠装饰线。

## 4. 图形语言

- **白板 / 扁平矢量示意**：矩形分层条、简单箭头、圆角徽章、厂房块抽象线框。
- 允许轻量「纪录片感」：纸质底、极淡阴影（软、短）；**不要**写实晶圆 macro、炫光芯片渲染。
- 图标：线性或扁平面性（车、充电桩、太阳、厂房），单色或双色。

## 5. Do

- 封面与收尾用大字标题 + 角标「仓内试稿 · 非投资建议」。
- 产能/年份帧醒目标注 **「规划 ≠ 已实现」** / **「前瞻 ≠ 已实现」**。
- 对照帧保留 **「IGBT ≠ SiC｜须分列」**。
- 高信息：层次标签齐全，但每层一句，不塞段落。
- 16:9 横屏；成片目标 1920×1080。

## 6. Don't

- 霓虹描边、扫描线、玻璃拟态、全息面板、科幻 HUD。
- 炫光 SiC 晶圆 / 金属芯片英雄图当主视觉。
- 任何单一衬底「市占 X%」；买卖点 / 目标价 / 涨跌暗示。
- 把 GaN / IGBT 视觉元素标成 SiC。
- 英文花体装饰压过中文可读性。
